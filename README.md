AgroConnect 🌾

AgroConnect is a web-based agricultural marketplace designed to connect farmers, agricultural input sellers, and buyers across Nigeria’s South-South region. It facilitates the buying and selling of agricultural produce, livestock, processed products, and farming supplies.

Features:
- User registration and authentication
- Product listings and management
- Shopping cart and order management
- Secure, role-based access
- Seller bank details and payout information
- Administrative management of users, products, orders, and complaints

Tech Stack:
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Authentication:** JSON Web Tokens (JWT)

Target Region:
Akwa Ibom, Bayelsa, Cross River, Delta, Edo, and Rivers States.

Purpose:
AgroConnect aims to make agricultural trading more accessible by providing a centralized digital platform for agricultural products and farming supplies.
